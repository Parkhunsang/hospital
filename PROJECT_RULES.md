# Project Rules

- Treat the project as a portfolio-quality static website.
- Codex handles HTML, CSS, layout, responsive styling, images, assets, and file organization.
- Do not create or modify JavaScript unless the user explicitly asks.
- Keep `reset.css` unchanged unless explicitly asked.
- Prefer `common.css` for shared styles and `main.css` for page-specific styles.
- Avoid inline styles.
- Structure HTML into reusable, semantic blocks using `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, proper headings, accessible links, and labeled forms, optimized for portfolio quality and future React conversion.
- Preserve existing user edits and inspect the project before changing files.
